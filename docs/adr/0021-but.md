# 0021 — but: adversative coordination enabled

Date: 2026-09-01
Status: proposed (tentative). Revises ADR 0004's deferral.

## Context

ADR 0004 deferred *but* as "rhetoric, not information". The ADR sweep (×3)
prompted re-examination: *but* marks that the second conjunct contradicts
the expectation set by the first — reader-expectation management, an
ADR 0006 comprehension aid, not decoration. Structurally it is clean: no
reference, no scope beyond what and/or already carry.

## Decision

- *but* joins CONJ with one fiat meaning: adversative coordination. All
  existing coordination rules apply unchanged (binary only, identical
  categories, ADR 0004 modifier rules).
- Sentence-initial *But* (cross-sentence discourse connective) stays out —
  *but* joins clauses within a sentence only, preserving the first-token
  telegraph. Enforced by construction: no sentence form starts with CONJ.
- The preposition sense ("all but one") is unwritable (*all* is banned).

## Consequences

- Contrast becomes expressible without meaning-flattening rephrases.
- First CONJ whose semantic contribution exceeds truth-functional
  connection; accepted because it adds signal without adding ambiguity.
